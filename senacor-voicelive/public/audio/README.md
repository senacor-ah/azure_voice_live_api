# Demo Audio Phrases

Place the following MP3 files in this directory:

| File | Phrase |
|------|--------|
| `phrase-ueberweisung.mp3` | "Ich möchte eine Überweisung machen" |
| `phrase-konten.mp3` | "Welche Konten bietet ihr an?" |
| `phrase-termin.mp3` | "Ich hätte gerne einen Termin bei meinem Berater" |

These files are used by the suggestion buttons in avatar mode.
